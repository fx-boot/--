# Hotfix 补丁版交付报告模板

> **用途**：当 v0.6.11（或后续发布版）的**阻断 / 高严重** Bug 按 [`hotfix-build-rule.md`](hotfix-build-rule.md) 完成修复、校验、打包、打 tag 后，助手**自动套用本模板**输出当次补丁交付报告，不得缺项、不得填入未经证据支持的结论。
> **使用方式**：复制下方分隔线之间的整块模板，替换所有 `<尖括号占位符>`；无内容项写「无」，不得删除章节。

---
