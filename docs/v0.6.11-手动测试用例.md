# 澜川Dola管理器 v0.6.11 · 手动测试用例清单

> **用途**：v0.6.11 便携版的人工自测清单，按「基础冒烟 → 边界场景 → 体验专项 → 批量与多账号」四类组织，可直接照步骤执行。
> **硬性约束**：平台侧链路**只允许使用「提交前校验（不发送）」**验证；**禁止真实点击「生成视频」**（会消耗对应账号额度）。凡涉及真实出片的用例一律标 ⏭ 跳过。
> **被测对象**：`_build-v0.6.11\澜川Dola管理器-v0.6.11-便携版\`（程序版本 v0.6.11，包内 `app/version.json` 可核对）
> **结果填写**：`[ ] 通过　[ ] 失败　[ ] 跳过（原因）`；失败请记录截图 + 底部「缺陷记录模板」。

## 0. 测试准备（一次性）

### PREP-01 环境准备
- 步骤：
  1. 关闭**正在运行**的旧版程序（避免旧版占用数据目录；不要删除旧目录，便于回滚）。
  2. 解压 `澜川Dola管理器-v0.6.11-便携版.zip` 到独立目录；确认包内 `isolated-data` **为空或不存在**。
  3. 双击 `澜川Dola管理器.exe` 启动；确认窗口标题与左上角品牌为「澜川Dola管理器 · v0.6.11」。
  4. 确认左下角版本徽标显示 `v0.6.11`；点击徽标可打开「关于 / 更新日志」，日志含本轮数据安全与体验条目。
  5. 确认左上账号列表能读到既有账号（若为空：先「添加账号」或「导入」一个账号并登录 dola.com）。
- 预期：启动无报错；版本号三处（品牌行、左下角徽标、关于弹窗）均为 v0.6.11；账号可见。
- 结果：[ ] 通过　[ ] 失败　[ ] 跳过

> ⚠️ 若需要沿用旧数据：先关闭软件 → 备份旧目录的 `isolated-data` → 复制到新版本目录 → 再启动（**不要覆盖已有新数据**）。
